# 機器手臂技術 · 學科 50 題 刷題系統

114 年全國技能競賽（工科賽）機器手臂技術職種 學科 50 選擇題練習網頁。

純前端靜態網頁，無後端、無追蹤，進度存在各自瀏覽器 localStorage。

## 模式
- **練習** — 全 50 題隨機，作答即顯示正解
- **錯題** — 自動收錄答錯題（答對自動移除）
- **模擬考** — 計時 + 答題卡 + 交卷及格判定（60 分）+ 逐題檢討
- **狂刷錯題** — 一鍵循環刷錯題到全清

## 功能
題序/選項隨機、圖片放大、字級/字重調整、淺/深主題。

## 使用
直接開 `index.html` 即可，或部署到任意靜態主機（GitHub Pages / Netlify / Cloudflare Pages）。
